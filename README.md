# 조각보 (Jogakbo) 데모

흩어진 논문 조각을 모아 읽고, 정리하고, 원고로 꿰매는 연구 도우미예요. 논문 찾기, 원문·번역·요약을 한 화면에서 읽기, 핵심 문장 형광펜, 모음 정리, LaTeX·Markdown 원고 작성과 인용 검증까지 한 앱에서 해요.

> 지금 판은 아는 분들께 먼저 보여 드리는 **데모**예요. 고칠 점이나 바라는 기능은 앱의 **문의(신문고)** 탭이나 goldeye3333@gmail.com으로 알려 주세요.

## 필요한 것

- Windows 10·11 (64비트)
- 디스크 여유 공간 2GB 이상(설치하면 약 1.6GB)
- 인터넷 연결(논문 검색, AI 기능)
- AI 기능을 쓰려면 본인의 API 키(예: Anthropic, OpenAI). 키 없이도 검색·읽기·정리·원고 작성은 돼요.

## 설치

1. 오른쪽 **Releases**에서 가장 위 판을 열고 `Jogakbo_…_x64-setup.exe`를 받아요.
2. 받은 파일을 두 번 눌러 실행해요.
3. **"Windows의 PC 보호"** 창이 뜨면 **추가 정보**를 누른 뒤 **실행**을 눌러요.
   데모 판은 코드 서명을 하지 않아 Windows가 "게시자를 알 수 없음"으로 경고해요. 이 저장소의 Releases에서 받은 파일이면 실행해도 돼요.
4. 한국어 설치 화면을 따라가요. 관리자 권한은 묻지 않고 내 계정에만 설치돼요.
5. 시작 메뉴에서 **Jogakbo**를 열어요. 처음 열 때는 준비하느라 조금 걸려요.

WebView2 런타임이 없는 PC라면 설치 중에 자동으로 받아요.

## 처음 쓸 때

- 첫 화면에 안내 창이 떠요. **둘러보기**를 누르면 바늘이 화면을 돌며 기능을 하나씩 알려 줘요(도움말에서 다시 볼 수 있어요).
- **시작 안내**에서 AI 연결을 고르고 API 키를 넣어요. 키는 Windows 자격 증명 관리자에만 저장되고 다른 곳으로 보내지 않아요.
- AI 기능(요약·번역·질의 등)은 단추를 누를 때만 불러요. 논문을 열기만 해서는 요금이 들지 않아요.

## 업데이트

새 판이 나오면 앱을 열 때 "새 판이 있어요" 창이 떠요. **예**를 누르면 받아서 설치하고 다시 열려요. 내 논문·원고·설정은 그대로 남아요.

## 지우기

**설정 → 앱 → 설치된 앱 → Jogakbo → 제거**를 눌러요.
앱은 지워져도 내 자료(논문 PDF, 원고, 읽기 기록)는 `%LOCALAPPDATA%\paper-scout` 폴더에 남아요. 완전히 지우려면 그 폴더도 지워 주세요. 저장한 API 키는 Windows **자격 증명 관리자**에서 `paper-scout`로 시작하는 항목을 지우면 돼요.

## 받은 파일 확인(선택)

Release에 있는 `SHA256SUMS.txt`의 값과 받은 파일의 값을 비교할 수 있어요. PowerShell에서:

```powershell
Get-FileHash .\Jogakbo_1.0.0-demo_x64-setup.exe -Algorithm SHA256
```
